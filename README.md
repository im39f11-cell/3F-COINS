# متجر عصّف - FC 27 Coins Store

موقع متجر إلكتروني كامل لبيع كوينز FC 27

## طريقة الرفع على GitHub Pages

1. أنشئ مستودع جديد على GitHub (مثلاً: `asaf-store`)
2. ارفع الملفين:
   - `index.html`
   - `logo.png`
3. اذهب إلى Settings → Pages
4. اختر Branch: `main` و Folder: `/ (root)`
5. احفظ وانتظر دقيقة، ثم افتح الرابط

## المميزات

- تصميم احترافي بألوان اللوقو (أسود + ذهبي + فضي)
- خلفية متحركة (جزيئات ذهبية)
- تأثيرات 3D على بطاقات التحديات
- سلة مشتريات + إتمام الطلب عبر واتساب
- أقسام: كوينز (PC/PS/Xbox) + رايفلز + فوت + مهام + تحديات
- الضمان الذهبي
- متجاوب بالكامل مع الجوال

## تعديل الأسعار

افتح ملف `index.html` وابحث عن:
- `coinPackages` لتعديل أسعار الكوينز
- `rivals` و `futRanks` و `missions` و `challenges` لتعديل الباقي
